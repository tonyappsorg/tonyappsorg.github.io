A familiar workflow

Make every customer email feel like your store

Order confirmations, shipment updates and account emails should be easy to recognise and easy to read. Work on them in the Magento admin with sections, text, images, buttons and blocks for the details each email needs.

01

Start from the right content

Tonyapps emails open with ready-made layouts. Magento sales emails offer blocks for items, addresses, tracking details and more.

02

Preview before you save

Check desktop and mobile widths with sample data or a suitable recent store record, then send a test to an address you choose.

03

Keep Magento in control

Saved designs are ordinary Magento email templates. Select one in the email's normal configuration setting; Magento sends it as usual.

How it works

From idea to usable template

  1. 01

    Choose an email

    Open Marketing › Communications › Email Designer and pick a transactional email from your store.

  2. 02

    Design visually

    Arrange content, insert available values, and apply your colours, font, buttons and footer.

  3. 03

    Check the result

    Preview at desktop or mobile width and send yourself a test email.

  4. 04

    Use it in Magento

    Save the design, then select it in that email's setting under Stores › Configuration.

Made for real store emails

Useful blocks, your brand, a way back

Add images from Magento's media gallery or by URL. Set one brand theme for colours, font, button shape and footer; each store view keeps its own email logo. If a change does not look right, restore one of the previous ten saved versions.

The editor and email layout tools are bundled with the module, so opening the editor does not depend on a CDN.

Emails you can design

  • Magento order, invoice, shipment and credit memo emails
  • Account and other transactional templates known to the store
  • Tonyapps company, quote and approval emails
  • Tonyapps cart, review and product alert emails

Get started

Install Visual Email Designer

Requires Magento Open Source 2.4 (developed on 2.4.8) and PHP 8.3 or 8.4. Grant admins access to Email Designer; image uploads also need the Media Gallery permission.

After installation, create a design under Marketing › Communications › Email Designer and select it in the relevant email setting.

composer require tonyapps/module-email-designer
bin/magento module:enable Tonyapps_EmailDesigner
bin/magento setup:upgrade

Good to know

Common questions

Will this replace Magento's email system?

No. Magento still sends each message. The designer creates a normal template for Magento to use.

Can I preview an email with a real order or quote?

Yes, when a suitable recent record exists. You can also use sample data. A test email goes only to the address you enter.

Will saved designs keep sending if I disable the module?

Yes. They remain ordinary Magento templates. Visual editing is unavailable until the module is enabled again.

Can I turn an existing hand-edited HTML template into a visual design?

No. Start from a ready-made layout or a new design. Hand-edited HTML templates cannot be converted into editable visual projects.

Can I use it for newsletters?

No. The designer is for transactional emails. It does not run newsletter campaigns, A/B tests or open and click tracking.
